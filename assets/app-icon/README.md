# Qanloom branding

Qanloom uses the approved original blue-and-gold document-and-stylus symbol with a
new outlined Qanloom wordmark (2026-10-30). The name is inspired by Mesopotamian
reed-stylus writing. The icon is SVG geometry; the wordmark uses outlined OFL Inter.

`nisaba.svg` is the editable symbol; `nisaba-logo.svg` is the self-contained outlined
wordmark source, rendered to `nisaba-logo.png`. `packaging/icons.sh` regenerates
Windows ICO, macOS ICNS, runtime PNG and Linux/FreeBSD hicolor renditions.

Legacy basenames and app IDs are retained for upgrade compatibility. Previous
artwork remains in Git history. Upstream licences and attribution are retained.
